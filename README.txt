TIGO LIVE STUDIO — PROYECTO ACADÉMICO DÍAS 1 Y 2

Archivos: index.html, styles.css, script.js.

EJECUCIÓN:
1. Descomprimir el ZIP.
2. Abrir con Live Server de VS Code (http://localhost) o publicar en GitHub Pages (HTTPS).
3. Autorizar cámara y micrófono. Iniciar Live para comenzar la sesión local.
4. Simular clientes, comentarios, regalos, likes, compras y variantes.
5. Observar bitácora visible y exportar registros/pedidos a CSV.

EVENTOS EXIGIDOS:
Día 1: click en ofertas y likes, dblclick en video para corazones, keyup en chat, delegación de eventos sobre #products, propagación DOM, 3 productos iniciales.
Día 2: change en variantes/cantidad/pago, submit + preventDefault en compras, validaciones y registro de transacciones en bitácora.

EXTRAS: modo claro/oscuro persistente, hamburguesa, cámara y micrófono, grabación WebM (si navegador compatible), regalos ficticios, clientes simulados que piden comprar, stock, estadísticas, persistencia local, CSV.

AVISO: No es TikTok oficial. No hay espectadores ni pagos reales. Los precios son inventados con fines educativos. No subir datos reales de clientes. La grabación captura cámara/micrófono, no los elementos HTML superpuestos. Para transmisión pública se necesita backend/servicio de streaming.
